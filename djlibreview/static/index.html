How a candidate is chosen

Clean, Dirty, and Super Clean stay apart. Intro and Hype Intro stay apart. Instrumental and Acapella stay apart. Radio Edit and Extended stay apart. VIP and Dub stay apart.

A named remix or editor stays in the qualifier, so two different names do not collapse. A BPM transition range stays in the qualifier. Unknown words stay significant. A file with no version tag is unlabeled and uncertain, not Original. A trailing (2) is only a copy hint and is not stripped.

This desk would rather miss a candidate than treat different DJ edits as the same file. There is no keep or delete control. Matching text never authorizes a change to a music file.

The sample file examples/row_problems.csv shows empty rows, a bad status, and out-of-scope text. Review it with scope /synthetic/dj-library and any real snapshot date.
